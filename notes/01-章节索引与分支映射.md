```bash

```

## 新手如何使用本索引

如果你正在按顺序学习，建议每开始一节都先回到本索引确认三件事：

1. 当前小节属于哪个章节和业务阶段。
2. 主要涉及哪个模块，例如 `merchant-admin`、`distribution`、`engine` 或 `settlement`。
3. 是否有对应分支或 diff 附录；如果没有，就以最终代码和正文解释为主。

如果你是按问题倒查，比如只想理解“消息幂等”，可以先在本索引中找到第 22 小节，再回到第 35 小节看面试复盘。
