## 2. 教程核心内容提炼

第 25 小节创建预约后发送延时消息。本节补齐消息到期后的处理：

1. RocketMQ 到期投递预约提醒消息。
2. 消费者收到消息并转换成提醒 DTO。
3. 调用 `CouponTemplateRemindExecutor`。
4. 执行器根据提醒方式选择 App 或邮件策略。
5. 执行器用线程池异步发送提醒。
6. 执行前写 Redis 检查 Key，并放入 Redisson 延迟队列兜底。
7. 如果线程池任务宕机未完成，延迟队列后台线程重新投递 MQ。

这是“消息触发 + 线程池执行 + 延迟队列兜底”的组合设计。

## 4. 延时消息消费者

`CouponTemplateRemindDelayConsumer`：

```java
@Component
@RequiredArgsConstructor
@RocketMQMessageListener(
        topic = "one-coupon_engine-service_coupon-remind_topic${unique-name:}",
        consumerGroup = "one-coupon_engine-service_coupon-remind_cg${unique-name:}"
)
@Slf4j(topic = "CouponTemplateRemindDelayConsumer")
public class CouponTemplateRemindDelayConsumer implements RocketMQListener<MessageWrapper<CouponTemplateRemindDelayEvent>> {

    private final CouponTemplateRemindExecutor couponTemplateRemindExecutor;

    @Override
    public void onMessage(MessageWrapper<CouponTemplateRemindDelayEvent> messageWrapper) {
        log.info("[消费者] 提醒用户抢券 - 执行消费逻辑，消息体：{}", JSON.toJSONString(messageWrapper));

        CouponTemplateRemindDelayEvent event = messageWrapper.getMessage();
        CouponTemplateRemindDTO couponTemplateRemindDTO = BeanUtil.toBean(event, CouponTemplateRemindDTO.class);

        couponTemplateRemindExecutor.executeRemindCouponTemplate(couponTemplateRemindDTO);
    }
}
```

消费者只做轻量工作：

- 打日志。
- 转换 DTO。
- 交给执行器。

实际发送提醒由执行器完成。

## 6. 提醒执行器

`CouponTemplateRemindExecutor`：

```java
@Component
@RequiredArgsConstructor
public class CouponTemplateRemindExecutor {

    private final SendEmailRemindCouponTemplate sendEmailRemindCouponTemplate;
    private final SendAppMessageRemindCouponTemplate sendAppMessageRemindCouponTemplate;

    private final RedissonClient redissonClient;
    private final StringRedisTemplate stringRedisTemplate;

    private final ExecutorService executorService = new ThreadPoolExecutor(
            Runtime.getRuntime().availableProcessors() << 1,
            Runtime.getRuntime().availableProcessors() << 2,
            60,
            TimeUnit.SECONDS,
            new SynchronousQueue<>(),
            new ThreadPoolExecutor.CallerRunsPolicy()
    );
}
```

线程池参数说明：

- 核心线程数：CPU 核数乘 2。
- 最大线程数：CPU 核数乘 4。
- 队列：`SynchronousQueue`，不堆积任务。
- 拒绝策略：`CallerRunsPolicy`，线程池满时由提交任务的线程执行。

提醒发送通常是 IO 密集型任务，所以线程数可以比 CPU 核心数多一些。

## 7. 执行提醒逻辑

```java
public void executeRemindCouponTemplate(CouponTemplateRemindDTO couponTemplateRemindDTO) {
    RBlockingDeque<String> blockingDeque = redissonClient.getBlockingDeque(REDIS_BLOCKING_DEQUE);
    RDelayedQueue<String> delayedQueue = redissonClient.getDelayedQueue(blockingDeque);
    String key = String.format(
            COUPON_REMIND_CHECK_KEY,
            couponTemplateRemindDTO.getUserId(),
            couponTemplateRemindDTO.getCouponTemplateId(),
            couponTemplateRemindDTO.getRemindTime(),
            couponTemplateRemindDTO.getType()
    );
    stringRedisTemplate.opsForValue().set(key, JSON.toJSONString(couponTemplateRemindDTO));
    delayedQueue.offer(key, 10, TimeUnit.SECONDS);

    executorService.execute(() -> {
        switch (Objects.requireNonNull(CouponRemindTypeEnum.getByType(couponTemplateRemindDTO.getType()))) {
            case APP -> sendAppMessageRemindCouponTemplate.remind(couponTemplateRemindDTO);
            case EMAIL -> sendEmailRemindCouponTemplate.remind(couponTemplateRemindDTO);
            default -> {
            }
        }

        stringRedisTemplate.delete(key);
    });
}
```

关键点：

- 执行前写一个 Redis 检查 Key。
- 把 Key 放入 Redisson 延迟队列，10 秒后检查。
- 线程池异步执行提醒。
- 提醒成功后删除检查 Key。

如果 10 秒后 Key 仍存在，说明提醒任务可能没完成。

## 8. 延迟队列兜底

内部类 `RefreshCouponRemindDelayQueueRunner`：

```java
@Component
@RequiredArgsConstructor
static class RefreshCouponRemindDelayQueueRunner implements CommandLineRunner {

    private final CouponTemplateRemindDelayProducer couponRemindProducer;
    private final RedissonClient redissonClient;
    private final StringRedisTemplate stringRedisTemplate;

    @Override
    public void run(String... args) {
        Executors.newSingleThreadExecutor(...)
                .execute(() -> {
                    RBlockingDeque<String> blockingDeque = redissonClient.getBlockingDeque(REDIS_BLOCKING_DEQUE);
                    for (; ; ) {
                        try {
                            String key = blockingDeque.take();
                            if (stringRedisTemplate.hasKey(key)) {
                                CouponTemplateRemindDelayEvent event =
                                        JSONUtil.toBean(stringRedisTemplate.opsForValue().get(key), CouponTemplateRemindDelayEvent.class);
                                couponRemindProducer.sendMessage(event);
                                stringRedisTemplate.delete(key);
                            }
                        } catch (Throwable ignored) {
                        }
                    }
                });
    }
}
```

兜底逻辑：

1. 应用启动后开启后台线程。
2. 线程阻塞等待 Redisson 队列。
3. 10 秒后拿到检查 Key。
4. 如果 Redis 中还有这个 Key，说明提醒未完成。
5. 重新投递 RocketMQ 提醒消息。
6. 删除检查 Key。

## 9. Spring Boot 与框架语法补充

### 9.1 策略模式

策略接口：

```java
public interface RemindCouponTemplate {
    boolean remind(CouponTemplateRemindDTO dto);
}
```

不同实现：

```java
public class SendEmailRemindCouponTemplate implements RemindCouponTemplate {}
public class SendAppMessageRemindCouponTemplate implements RemindCouponTemplate {}
```

调用方根据类型选择策略，避免大量 `if else` 散落在业务里。

### 9.2 `switch` 箭头语法

```java
switch (type) {
    case APP -> sendApp.remind(dto);
    case EMAIL -> sendEmail.remind(dto);
}
```

这是新版 Java 的 switch 写法，比传统 `case` 加 `break` 更简洁。

### 9.3 `CallerRunsPolicy`

线程池满时，提交任务的线程自己执行任务。

```java
new ThreadPoolExecutor.CallerRunsPolicy()
```

它不会丢任务，但会拖慢调用线程，形成一种自然限流。

### 9.4 Redisson 延迟队列

```java
RBlockingDeque<String> blockingDeque = redissonClient.getBlockingDeque("queue");
RDelayedQueue<String> delayedQueue = redissonClient.getDelayedQueue(blockingDeque);
delayedQueue.offer("key", 10, TimeUnit.SECONDS);
String key = blockingDeque.take();
```

`offer` 后不会立刻被 `take` 取到，必须等延迟时间到。

### 10.5 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 消息不到期 | delayTime 计算不对 | 检查模板开始时间和 remindTime |
| 提醒策略不执行 | type 和枚举不匹配 | 检查 `CouponRemindTypeEnum` |
