# 第 25 小节：开发优惠券预约通知功能（一）

## 新手先读

本节做的是用户预约优惠券开抢或到期提醒。你可以把它理解成：用户选择某个提醒时间和提醒方式，系统到点后再通知用户。

Bitmap 是本节难点。先把它理解成“用一个数字的多个二进制位保存多个开关”，比如第 1 位代表站内信，第 2 位代表短信，第 3 位代表邮件。

## 2. 教程核心内容提炼

有些优惠券还没到开抢时间，用户希望在开抢前收到提醒。预约提醒需要保存：

- 哪个用户预约。
- 哪个优惠券模板。
- 提醒方式，比如 App、邮件。
- 提前多久提醒，比如提前 5 分钟、10 分钟。
- 优惠券开抢时间。

本节通过一张预约提醒表保存用户预约，并用 bitmap 把“提醒方式 + 提醒时间”压缩成一个 `Long information` 字段。

创建预约后，系统发送一条 RocketMQ 延时消息，到提醒时间后再通知用户。

## 5. bitmap 设计

`CouponTemplateRemindUtil`：

```java
public class CouponTemplateRemindUtil {

    private static final int NEXT_TYPE_BITS = 12;

    private static final int TIME_INTERVAL = 5;

    public static Long calculateBitMap(Integer remindTime, Integer type) {
        if (remindTime > TIME_INTERVAL * NEXT_TYPE_BITS) {
            throw new ClientException("预约提醒的时间不能早于开票前" + TIME_INTERVAL * NEXT_TYPE_BITS + "分钟");
        }
        return 1L << (type * NEXT_TYPE_BITS + Math.max(0, remindTime / TIME_INTERVAL - 1));
    }
}
```

设计含义：

- 每种提醒方式占 12 个 bit。
- 每 5 分钟一个提醒档位。
- 一种提醒方式最多支持提前 60 分钟。
- `type * 12` 用于切换提醒方式分区。
- `remindTime / 5 - 1` 用于定位具体提前分钟档位。

示例：

| type | remindTime | bit 位置 |
| --- | --- | --- |
| 0 | 5 | 0 |
| 0 | 10 | 1 |
| 0 | 60 | 11 |
| 1 | 5 | 12 |
| 1 | 10 | 13 |

## 6. 创建预约提醒流程

`CouponTemplateServiceRemindImpl#createCouponRemind`：

```java
@Override
@Transactional
public void createCouponRemind(CouponTemplateRemindCreateReqDTO requestParam) {
    CouponTemplateQueryRespDTO couponTemplate = couponTemplateService
            .findCouponTemplate(new CouponTemplateQueryReqDTO(requestParam.getShopNumber(), requestParam.getCouponTemplateId()));

    LambdaQueryWrapper<CouponTemplateRemindDO> queryWrapper = Wrappers.lambdaQuery(CouponTemplateRemindDO.class)
            .eq(CouponTemplateRemindDO::getUserId, UserContext.getUserId())
            .eq(CouponTemplateRemindDO::getCouponTemplateId, requestParam.getCouponTemplateId());
    CouponTemplateRemindDO couponTemplateRemindDO = couponTemplateRemindMapper.selectOne(queryWrapper);

    if (couponTemplateRemindDO == null) {
        couponTemplateRemindDO = BeanUtil.toBean(requestParam, CouponTemplateRemindDO.class);
        couponTemplateRemindDO.setStartTime(couponTemplate.getValidStartTime());
        couponTemplateRemindDO.setInformation(CouponTemplateRemindUtil.calculateBitMap(requestParam.getRemindTime(), requestParam.getType()));
        couponTemplateRemindDO.setUserId(Long.parseLong(UserContext.getUserId()));

        couponTemplateRemindMapper.insert(couponTemplateRemindDO);
    } else {
        Long information = couponTemplateRemindDO.getInformation();
        Long bitMap = CouponTemplateRemindUtil.calculateBitMap(requestParam.getRemindTime(), requestParam.getType());
        if ((information & bitMap) != 0L) {
            throw new ClientException("已经创建过该提醒了");
        }
        couponTemplateRemindDO.setInformation(information ^ bitMap);

        couponTemplateRemindMapper.update(couponTemplateRemindDO, queryWrapper);
    }

    CouponRemindDelayEvent couponRemindDelayEvent = CouponRemindDelayEvent.builder()
            .couponTemplateId(couponTemplate.getId())
            .userId(UserContext.getUserId())
            .contact(UserContext.getUserId())
            .shopNumber(couponTemplate.getShopNumber())
            .type(requestParam.getType())
            .remindTime(requestParam.getRemindTime())
            .startTime(couponTemplate.getValidStartTime())
            .delayTime(DateUtil.offsetMinute(couponTemplate.getValidStartTime(), -requestParam.getRemindTime()).getTime())
            .build();
    couponRemindDelayProducer.sendMessage(couponRemindDelayEvent);
}
```

流程：

1. 查询优惠券模板，确认模板存在并拿到开抢时间。
2. 查询当前用户是否已有预约记录。
3. 如果没有，插入一条预约记录。
4. 如果有，用 bitmap 判断是否已经预约过同一提醒。
5. 没预约过则把对应 bit 打开。
6. 发送延时消息，在开抢前指定分钟数触发。

## 7. 位运算解释

判断是否已预约：

```java
if ((information & bitMap) != 0L) {
    throw new ClientException("已经创建过该提醒了");
}
```

含义：如果 `information` 中已经包含这个 bit，按位与结果不为 0。

新增提醒：

```java
couponTemplateRemindDO.setInformation(information ^ bitMap);
```

这里在已确认 bit 不存在的情况下，`^` 可以把该 bit 从 0 变成 1。

更常见的写法是：

```java
information | bitMap
```

因为按位或更直观地表示“打开某一位”。本节使用 `^` 的前提是前面已经判断这个 bit 不存在。

## 8. 延时消息时间

提醒时间计算：

```java
DateUtil.offsetMinute(couponTemplate.getValidStartTime(), -requestParam.getRemindTime()).getTime()
```

如果优惠券 `10:00` 开抢，用户选择提前 5 分钟提醒，那么消息投递时间是：

```text
09:55
```

RocketMQ 延时消息到达后，后续章节会消费这条消息并真正发送提醒。

## 9. Spring Boot 与框架语法补充

### 9.1 `1L << n`

```java
long bitMap = 1L << 3;
```

二进制含义：

```text
0001 << 3 = 1000
```

适合用一个 Long 表示多个开关状态。

### 9.2 按位与 `&`

```java
boolean exists = (information & bitMap) != 0;
```

用于判断某一位是否已经是 1。

### 9.3 按位异或 `^`

```java
long newValue = information ^ bitMap;
```

用于翻转某一位：0 变 1，1 变 0。

### 9.4 `@Transactional`

本节插入或更新预约记录后，还要发送消息。数据库操作用事务保护。注意：消息发送不属于数据库事务，生产环境如果要求强一致，需要本地消息表或事务消息补偿。

## 11. 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 提醒时间不合法 | `remindTime > 60` | 按 5 分钟档位设置 |
| 重复预约报错 | 同一 bit 已存在 | 换提醒方式或提醒时间 |
| 查不到模板 | 模板不存在或缓存未命中 | 先创建有效模板 |
| 消息没发送 | RocketMQ 未启动 | 检查 MQ 配置 |
